# SCN_01 雨落山径：Blender 原型源资产入库

本工作单元将首个场景的真实可编辑模型和可用交换格式放入 AetherLab，便于继续制作与后续 UE 导入。它不是运行时地图接入，也不是精修成品美术；没有修改现有地图、角色、动画蓝图或玩法代码。

## 目录

`Art/AetherLab/Scenes/SCN_01/`

- `source/SCN_01_Rain_Mountain_Path.blend`：完整编辑源，含语义集合、程序材质、灯光和摄影机
- `source/*.py`：Blender 建模、画面修订与交换格式回读检查脚本，均以脚本所在目录定位资产，不依赖制作机器的绝对路径
- `exports/SCN_01_Assembled.glb`：整体场景交换预览
- `exports/fbx/`：10 个分组 FBX，包括驿站、破轮货车、水桶、水面、棚下火盆/火焰、石路、矮墙、木栏、路灯和南门
- `previews/`：真实 Blender 总览和驿站细节渲染
- `docs/`：模块清单、几何计数、Blender 回读记录、哈希和限制说明

该目录是 DCC 源资产和 UE 导入暂存区，不在 `Content/` 中，不会被误认为已有 `.uasset` 或可 Cook 的运行资源。没有只提交 ZIP，也没有生成伪 `.uasset`。

## 已验证

使用 Blender 4.3.2 重开源文件；10 个 FBX 和整体 GLB 均成功回读。整体 GLB 保留 1796 个独立网格和两个组合根节点。水面、桶板、车轮/车身、火盆和火焰没有合成单一不可拆网格。水桶组含临时碰撞参照的尺寸为 1.236 × 1.236 × 1.4 米；单独水面为 0.86 × 0.86 × 0.02 米。

入库检查脚本：

```bash
python Scripts/Validate/ValidateBlenderArt.py --scene SCN_01
```

需要重新进行 Blender 回读时：

```bash
blender -b --python Art/AetherLab/Scenes/SCN_01/source/validate_SCN_01.py
```

这是资产文件及 Blender 验证，不是 UE 编译、规则测试或运行验收。UE 未编译、未测试、未导入，未运行 Cook。

## 后续导入契约

- Blender 使用米，UE 使用厘米；先测量验证，不盲目再加 100 倍缩放
- 保留交互件分离；水面、桶、轮、火盆/火焰具有各自语义身份
- FBX 当前保留场景空间放置，生产模块枢轴仍需按玩法校准
- 临时 UCX 参照不是已验证的 UE 碰撞；驿站仅有地基参照，门/背景无完整碰撞，需另做
- 程序风化和凹凸材质不会完整通过 FBX/GLB 传递，需烘焙贴图或建立 UE 材质
- 尚未完成 LOD、完整 UV/光照贴图验收、物理质量/约束、导航、反应绑定和性能预算

## 范围和取代关系

只包含 SCN_01 场景。此前独立 43 骨骼角色已被用户否决，本提交不包含其任何模型、导出、脚本或图片；正式主角须在真实 UE Manny 基础人体与原骨架上制作。仓库已有 Manny `.uasset`，当前云环境缺少可编辑的 Manny FBX/Blend 和 UE Editor，因此正在寻找可靠来源的真实 Manny 可编辑基模，取得并核验后再改造。
