# V8-05 结构变化与通行

已实现：作者配置的桥梁通行组件。在释放后检查平稳速度、角速度、姿态、碰撞及两端地面支撑，连续稳定 0.75 秒才开放导航连接和桥面导航几何；移动、倾覆、断裂或端点失去支撑时关闭，记录复制版本。AI 每次选取前进地面都检查当前通行状态，拒绝缓存路径上的不可用桥/冰面。

冰面阶段由服务器决定并复制：液态、冻结待生效、可承载、融化预警。新结冰时检查人物占位；即使材料进入休眠，离开占位后也会重新检查。承载判定使用实际冰质量，融化预警先撤掉导航，质量不足时撤销实体碰撞，不凭空补热/补冰或永久续冰。站在融化冰面上的 AI 优先朝最近边界撤离。

机械撞击采样物理步之前的线速度和角速度，用接触法线上的相对接近速度限制能量；持续支撑/挤压单独标记，不通过单次撞击重复扣血。玩法适配保留来源 5 秒过期和目标冷却，新增最低接近速度。没有新增持续挤压伤害、任意几何导航分析或网络物理预测。

验证：必要增量 Editor 编译和静态检查。运行中的落稳、冰面撤离与动态 NavMesh 路径仍待后续短检查；编译不等于运行验收。继续使用原有基础桥板、水面和官方人物模型。
