# v6 玩法后续实现

## 原生角色动画

- 使用已纳入版本控制的 UE 官方 Manny 基础模型与 Unarmed 占位动画。
- 原生 AnimInstance/Proxy 连接地面 BlendSpace、跳跃/下落/落地混合、攻击 Slot、双腿 TwoBoneIK 和格挡手臂姿势。
- 攻击蒙太奇按服务端攻击起始时间与前摇/有效/恢复窗口定位；占位片段采用 35%/65% 的阶段分界。装备定义可覆盖动画片段。伤害仍来自服务端扫掠，不由 Notify 发放。
- 足部射线仅用于附近可见、低速、地面且非攻击的角色，20 Hz 查询，双脚有效才混合 IK；这是基础实现，尚未做坡地视觉验收。
- 倒地/受击使用落地片段定格占位；未制作正式受击、武器姿势层、辅助握持 IK 或异步动画包系统。
