# 原生遭遇、营地与共享奖励

本单元未编译、未测试，只完成源码及人工边界复核。

遭遇成功先提交世界阶段/参与者/实例检查点，再入服务器结算队列。角色最后实例回执、每日奖励标记、任务事实、任务奖励/技能点与世界已结算名单在一个 SQLite 事务内比较并推进版本。重复请求依据实例与每日集合重算，不执行裸加币；满包奖励整份进入待领奖，不拆开授予。离线角色同样从持久 Profile 读取，世界发布不依赖对应 Pawn 在线。每个实例所有参与者都确认后，才允许覆盖为下一次遭遇。

营地清理创建原生世界 CAS 候选，同时保存掉落和重生 UTC。GameMode 保留未完成的 Future，收到提交确认才向营地状态机返回成功；未确认不生成场景战利品，也不提前开始冷却。周期检查点、任务事务和营地修改冲突时从最新聚合重读再采集。

迁移保留的旧共享掉落按 ClaimId 进入服务器原子领取：物品与 ClaimedBy 同时提交，多人竞争只会有一个领取者。满包时保持原掉落；已提交世界投影才删除实体。v10 完整实例掉落继续使用 Container 聚合，两条路径均不调用旧 SaveGame writer。

仍需继续完成正式交互/回执 UI 与故障矩阵验证。服务器日志中的失败不能算用户已收到成功回执，领取提示仅表示请求已入队。
