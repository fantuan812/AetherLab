# v10 容器生产链路

新增静态共享箱子和个人仓储的缺失创建、拥有者授权读取、背包容器格网、双向拖动与数量确认、掉落 E 键读取/拾取。创建仅接受空库存，不覆盖旧行；个人仓储允许角色自己的绑定物品，但存入仍禁止锁定与装备中物品。

协议 v3 在原有固定请求后追加 ExpectedContainerRevision。新拾取/转移同时固定角色、世界和容器版本；v1/v2 原字节继续支持回执查询，不能作为新容器写入执行。客户端保存确认后的原字节，不因刷新重新生成请求。

容器分片与角色快照共用每连接一个未确认片段和全局发送预算，轮换发送。查询只携带有限目标 ID、通道和页面 Context。打开、异步读取完成、发送前均检查会话、当前目标、权限、距离和视线；个人内容不放入 Actor 广播。关闭、离开范围、死亡或换 Pawn 后废弃该 Context。客户端只在完整 CRC/DTO 校验后替换展示。

转移详情固定来源容器与实例 GUID，仓储物品只能取出，不能直接穿戴/消耗。容量不足时按实际数量反馈，剩余保留原处。服务器全局发布不依赖提交者是否仍在线；私有角色快照仍受 epoch 约束。
