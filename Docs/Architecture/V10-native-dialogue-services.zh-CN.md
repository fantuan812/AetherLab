# v10 对话与现场服务

LocalPlayer 对话会话使用弱目标、通道和交互实例版本；每次点击校验所见页面版本，不把旧按钮替换成新意图。失去范围、视线、行动资格、Pawn 或目标时关闭。登记、旅舍、导师、商人、招募、公告板、修道院和中继入口可以在独立页面交谈，已完成服务与隐藏条件由相同只读提供者过滤。背景对象不显示虚假的交互提示。

持久操作继续使用原生事务与固定字节重试。休息、训练场景、交易开启、委托场景创建、取水、倒水、门、遭遇启动/引导是明确保留的现场机制输入：有限协议、拥有者通道、Pawn 复验、限流、通道内单调序号，只执行一次，不在重连后自动重放。开关门是设置目标值，水转移仍守恒。服务器以现场条件重建提供者并比较角色、世界和交互版本。

招募沿用当前在线队伍的生命期，最多四个真人/AI 席位、两个命名同伴不重复；仅个人招募历史与奖励进入持久服务器事实事务。队列拒收时撤销新实体；接受不冒充提交成功。训练和委托目标归本人，已完成火点不因重复交谈重新点燃，Pawn 结束会清理私人场景。救援保留原有明确目标、持续距离/视线、伤害中断与 GAS 服务。

现阶段状态：新增代码/数据未编译、未测试。正式 CommonUI 根栈、资源化页面、背包/修理页面和统一生命周期验收仍在后续工作包，不将独立对话源码视为完整 v10 验收。
