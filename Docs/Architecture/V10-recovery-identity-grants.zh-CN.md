# v10 世界身份、恢复与授权快照
- 世界 DTO 新增可选 RLM1 尾部扩展，旧数据无扩展仍可读取。首次基线 CAS 检查点生成 RealmId，后续捕获保留它；持久确认前不开放玩家绑定。
- 拥有者命令通道携带 RealmId。LocalPlayer 挂起队列按 RealmId + 精确角色身份查找，换世界同名角色不能重新授权旧意图；同世界重连仍要求用户明确重试原始命令字节。副本存档保留 RealmId，表示同一存档谱系。
- 后端排空期间拒绝重新安装，防止替换尚有写事务的协调者。初次登录结算也使用同一有界事实保留入口。
- 技能外部授权改为自定义 NetSerialize 的原子结构，包含档案版本、刷新序号、来源、实例、等级与到期时间。技能页与背包只合并对应版本；同档案版本刷新祝福也会触发页面失效。
- 原生模式死亡恢复创建新 Pawn，经统一资源生命恢复泵和消费投递账本重新开放操作，不再直接修改旧 Pawn 生命值并旅行。旧奖励领取字符串入口在原生模式只引导到任务页。
- 未编译、未测试；新的 DTO 向后兼容、原子复制、重连及恢复矩阵待全部代码完成后的统一验证。
