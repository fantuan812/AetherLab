# v10 菜单生命周期与兼容界面

本单元处理 V10-05 的状态所有权、输入开关、页面记忆和刷新生命周期。正式 CommonUI 页面栈、设计资产、图形背包/技能树、手柄提示仍待接入；旧文本正文没有因此成为正式 v10 UI。

## 状态与输入

- `UAetherMenuSubsystem` 属于 LocalPlayer。角色上的 `bPanel/Panel` 暂作旧玩法门禁镜像；快捷键、交易打开、关闭按钮与截图夹具经过统一入口。
- I/J/K/M/P 同键关闭、异键切页；Esc 优先取消旧出售确认，再逐层退出模态/详情，最后关页。没有菜单时 Esc 打开系统页。
- 打开/关闭时统一更新鼠标和输入模式；页间切换不重复 Flush。地图页也执行同样的本地动作门禁。在线世界不暂停。
- 控件获得焦点后，预览按键仍处理当前重映射后的菜单快捷键。录入新绑定期间交给改键控件处理。
- 详情/模态令牌只允许移除当前栈顶；页面切换、换 Pawn 后旧令牌失效。最多 8 层。
- 页面记忆按页保存搜索、滚动和完整实例 GUID；关闭/切页保留，换 Pawn 清空。搜索输入控件与实例网格还未实现。

## 发布与生命周期

- 已提交的旧档案走 `OnProfilePublished`；拥有者收到 Profile/显示名/队伍复制后走同一通知。SQLite 原生档案仍未替换生产 v9 档案。
- 命令挂起和回执另行通知，允许“回执先于属性复制”更新等待态，之后用实际拥有者快照更新正文。
- Widget 开关由菜单事件驱动，关闭时折叠并停掉实时定时器；不再用透明 Widget 保持 Tick。
- Widget 解绑旧 Pawn、旧 PlayerState 与菜单回调，再绑定新上下文。拆除时清除定时器。
- 仅交易距离/报价确认和队友生命以 0.25 秒周期更新；档案正文不再每帧拼接。
- 相对锚点由 UMG 处理窗口与 DPI 变化，不再逐帧写入绝对像素位置。
