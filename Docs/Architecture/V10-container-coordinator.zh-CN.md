# v10 容器命令与一致快照协调

## 当前范围

DropItem、PickUpItem、TransferItem 已进入正式的纯值命令处理器和异步 SQLite 协调器，总计支持 20 类命令。此处的“服务调用路径”指实际调用协调器/数据库，仍未绑定生产网络 RPC、场景 Actor 或两栏 UI。现场条件由服务器上下文接口提供，当前验证使用合成场景上下文。

## 一致读取

ReadSnapshot 在一个 SQLite 只读事务内读取最多四个聚合（合计最多 8 MiB）、可选角色版本索引和容器总数。不存在的 key 明确省略，便于创建新掉落；任一查询、schema、长度或索引异常会使整份结果失败，不返回部分值。

ReadRevisions 支持 Profile（128）、World（1）和 Container（4096）的有界版本索引，不列出 Migration。它用于启动恢复与内部跨引用验证，不能直接作为客户端容器列表。索引不含聚合私有负载，ID 校验无损 UTF-8 与控制字符。

## 授权与执行

Resolver 现在收到会话、有限命令和已提交角色，可按请求目标在服务器注册表解析授权。容器私有负载读取前先验证 bAuthorized、目标就绪、对应能力/会话和操作方向；客户端不能提供这些标志。读事务完成后再询问一次当前现场条件，目标变更、卸载或会话失效都会阻止提交。

候选层再次核对 DTO 与行版本、角色 ID、世界版本、容器 ID 和持久 owner。即使调用方错误标记个人仓储为已授权，其他角色仍无法转移其中物品，完成结果也不携带它的私有快照。

- 丢弃检查完整 CanRemove（绑定、锁定、任务、已装备等），使用服务器验证的区域与落点；创建共享 WorldDrop，或复用服务器选定的空非活动掉落记录。绝不覆盖活动掉落、普通箱子或个人仓储。新建容器受 4096 总量限制，复用记录推进原容器版本。
- 拾取必须具有 InventoryPickup 能力、安全收纳许可及读取权限，只读取 WorldDrop；允许按容量转移部分，保留剩余实例与状态。全部领取后保留非活动墓碑。
- 两栏转移需要有效容器会话及方向权限。个人仓储允许自己的绑定/锁定实例保持状态移入；共享容器使用公开转出限制，不能借存入完成误丢或绑定转移。持久 owner 始终复验。

角色、世界和容器在同一个事务中各推进一次；新容器从不存在写入 revision 0。成功回执记录容器键、版本和实例关系。发布前重读三聚合一致快照并校验不低于回执版本。竞争请求可返回冲突/旧版本，不能重复发物品。

## 重试与生命周期

回执优先于当前现场条件，已提交的领取可在交互会话关闭后重放原结果；不会重新取物或再次执行条件。重放只给同一已绑定角色会话，个人仓储快照再次受 owner 限制。WorldSnapshot 是服务器内部恢复/表现输入，不能作为全量网络广播数据。

沿用 SessionId/PawnEpoch 与游戏线程轮询约束，写入之前会话失效取消候选，写入之后失效禁止旧结果发布。三聚合快照只在持久成功后产生；所有失败完成结果清除候选数量与关系。
