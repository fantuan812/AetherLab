# v10 原生格子背包与详情宿主

正常原生角色的 I 页读取 LocalPlayer 已提交的 v10 库存快照。32 格使用持久 SlotIndex，十个装备槽只引用实例 GUID；筛选和搜索保留真实位置。角色预览独立于场景 Pawn，空副手会标明双手占用。鼠标右键与手柄确认进入持续详情；悬停只给摘要。装备比較要求明确槽位，戒指不会自动替换另一个槽。

拖放载荷固定拥有者通道、展示版本和实例。拖到空格、不同物品、同状态堆或装备槽分别提交移动、交换、合并或装备命令；从装备槽拖回背包只卸下引用。客户端不提前移动图标、不扣金币、不改耐久。原请求由统一命令服务保留，关页或详情刷新不生成替代请求。

详情会话新增使用、拆分、购买、出售和修理；数量确认显示报价合计，最终价格、距离、权限、资源与冷却全部由服务器重验。商店目录来自当前真实交易目标，失去会话立即撤销展示资格。键盘用药、主副手切换、循环选择和待领奖励已接原生协议；Delete 转入物品详情确认。

页面仅在打开时以 0.25 秒更新现场服务条件，正常背包更新由快照/回执驱动。没有状态变化时不重建详情按钮，不抢焦点。图标按有限 IconId 异步加载，并检查请求身份后发布；实际图标资源仍待统一制作阶段生成。

状态：未编译、未测试。双栏容器、CommonUI 根栈、最终 WBP/图标制作与统一运行验证继续实施，当前源码不代表这些工作已完成。
