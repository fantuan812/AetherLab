# v10 安全传送与手柄输入

传送在原地保留碰撞，使用独立 WorldPartition source 预加载目的地；原生区域兴趣包含两端。远程拥有者确认对应服务器 token 的本地流送、地面和胶囊净空后，服务器再次检查区域、坡度和完整胶囊空间，使用 TeleportTo 提交真实落点。20 秒超时或死亡取消并释放临时流送源，不反复传送回原点。成功客户端保留预加载源直到 Pawn 位置抵达，EndPlay 清理全部临时状态。

Enhanced Input 加载正式 IA/IMC 资产并仅修改上下文副本；作者脚本从绑定声明制作默认资源。摇杆带死区，视角使用独立灵敏度和每秒转速。A 跳跃/B 闪避/X 交互/Y 药剂，扳机攻击/格挡，摇杆按下冲刺/锁定，左肩下蹲、右肩施法，十字键选技能，左肩加十字键执行搬运/投掷/推动/法力药剂。菜单肩键切换六页；地图 X/Y 选标记、扳机缩放。设备断开、失焦和生命周期退出释放保持输入。
