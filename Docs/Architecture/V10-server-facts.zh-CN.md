# v10 服务器事实与任务结算

新增服务器专用事实队列，接收可信场景/战斗事件，没有客户端任意 ObjectiveId 的 RPC。

个人、世界、每日事实与自动任务结算使用同一 Profile/World 读取快照；金币、物品、待领奖、经验、Claims 和技能点来源一次事务提交。事实集合、Quest Claims 和 Quest 点数来源保持幂等；重复事件不重复发奖。世界首次来源不被后续观察改写，实际参与者与追溯规则分开处理。每日观察以入队时服务器 UTC 日期为准，不回退较新日历。

队列最多 128 条，每轮最多 16 个角色，各角色按入队顺序处理，重复在途事实合并。冲突重读重算；模糊提交结果先查原请求回执。自动重算仅限此队列的幂等集合/账本变更，不用于裸加金币、消耗或耐久扣减。

运行时在登录时补结算，世界事实成功后安排其他已连接角色补结算；新的已提交档案进入原生拥有者发布。训练木桩挑选事实时同时检查持久证据与在途记录，避免异步保存期间三次命中全落到 Melee1。灭火观察携带实际稳定实体来源；同伴归属沿用权威角色解析。
