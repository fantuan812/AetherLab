# v10 图形技能树（代码实现，未编译、未测试）

本单元推进 V10-12，并把现有 K 技能页的四行文字列表替换为独立图形页代码。仍为 in_progress，不能据此宣布完整成长闭环完成。遵守用户顺序，没有运行编译、规则测试、启动检查或资产制作脚本。

## 定义、布局和状态

- SkillTreeLayout.json 独立保存四系三级的 12 个坐标。解析器要求每个已定义等级恰好出现一次，拒绝未知等级、非有限/过大坐标、重复或重叠节点。文件随现有 Definitions 的 NonUFS 规则打包。
- 前置线由技能定义生成，包含同技能等级链以及跨技能分支/合流。编辑坐标不会改变可学习条件。
- 模型消费已授权快照，复用 CanLearnNext、PermanentRank 和 EffectiveRank。区分尚未开放、缺少前置、点数不足、可学习、已学习、可升级、满级、外部授予、处理中、暂不可学习。
- 学习待确认固定到发出时的节点。玩家改选其他路线不会把处理中状态移到新选择；不乐观写入永久等级。
- 快捷栏按稳定 SkillId 保留未授权但可辨识的槽位。点数来源按持久事件 ID 排序和分页，不生成虚假历史点数。

## 图形控件与操作

专用 Slate 控件绘制独立节点、元素几何占位图标、文字状态、前置箭头和精确命中区域。占位图标不是最终美术资源。支持点击/右键、悬停摘要、空白或中键拖动、鼠标位置锚定缩放、重置视图；方向键和手柄方向键沿前置链或相邻路线导航，超出视区时把选中节点移回可见区域。关闭页面释放自己的鼠标捕获与悬停。

右侧复用统一详情卡，底部显示四个快捷位与点数来源。数量/危险确认是独立遮罩层，使用菜单精确令牌判断 Esc 和切页失效。右键仅查看，不学习或施法。详情宽度改为可收缩的最大/最小期望值，完整分辨率效果仍待统一阶段检查。

## 当前生产接入与明确边界

现有 UAetherFrontierPanel 的 K 页面接入 UAetherSkillTreePage；旧技能正文不再拼接四行列表，其他页面沿用兼容 UI。

目前普通游戏仍使用冻结 v9 Profile。旧路径通过 FromLegacyMask 只映射故事基础授予和既有快捷位，不创建技能点、支付记录或高阶永久等级。此路径的学习/升级/绑定按钮明确禁用，保留导师授予入口；追踪已有前置任务只改变本地追踪目标。不能把只读展示误写成可支付成长。

原生 PublishSnapshot、ReceiveReceipt、OnCommandReady 已提供集成契约。正式网关发布真实 v10 快照并绑定命令服务后，操作才可派发；会话产生现有协议的固定请求字节，回执/快照等待沿用统一详情服务。宿主负责认证、发布版本推进、换 Pawn 会话隔离及未决命令持久重试，不得从客户端展示字段推断服务器身份。
