# v10 GAS 地面闪避

普通游戏 Alt 现在通过已授予的 UAetherDodgeAbility 激活本地预测能力。旧 ServerDodge 兼容入口也转入同一能力，不再执行 LaunchCharacter 或直接扣除体力。

## 权威、预测与成本

能力为 LocalPredicted / InstancedPerActor，重复激活不重入。GAS 的瞬时成本效果扣除 18 体力；0.7 秒冷却通过效果标签限制。客户端按预测键执行成本，服务器重新校验姿态、地面、动作、资源、搬运、救援和旅行条件。服务器拒绝时由 GAS 取消预测和恢复效果，不能用本地布尔值授予无敌或消费权。

角色只在站姿地面就绪时开始闪避，默认朝当前角色朝向。动作活动标签阻止跳跃、冲刺、格挡、武器动作与施法通过现有 Ready 检查插入。服务端保留 0.55 秒动作恢复期限供安全交互判断最近战斗时间；取消不会退回已支付的体力或冷却。

## 移动与取消

UAbilityTask_ApplyRootMotionConstantForce 产生引擎可复制的 RootMotionSource，覆盖水平速度，固定 700 cm/s 持续 0.35 秒，平地名义距离 245 cm。它仍经过 CharacterMovement 的地面、坡面、墙体扫描和网络纠正，不能直接改变 Actor 位置绕过碰撞。

开启重力对应 IgnoreZAccumulate，保留正常竖直物理。没有强制 Walking，也没有附加向上速度。结束时 ClampVelocity=0 停止剩余水平冲量，保留向下速度；越过平台边缘应继续自然下落。

能力恢复在 0.55 秒结束。服务器战斗无敌标签持续 0.22 秒，按现有 ReceiveHit 语义阻止战斗命中；环境直接伤害仍走既有规则。取消或换 Pawn 时结束任务并移除对应根运动与剩余无敌效果。清理绑定激活时的角色和 ASC，不能让迟到取消作用于后来接管的 Pawn。

## 当前范围

本单元只完成闪避的规则、预测、成本和受碰撞位移。人物仍使用 UE 官方占位资源，独立翻滚/侧步动画与最终动作融合尚未接入；没有把移动正确视作动画完成。数据化动作曲线、全部动作取消窗口、四人/丢包和发布验收仍待后续工作。

## 实测证据

- 非 Unity UE 5.8 Editor Development 编译通过：V10-dodge-build7.log。
- 66 项规则通过，无失败或警告：Rules-5954e979c9784c47aa08534e2d32aad2。实际 CharacterMovement Tick 验证成本只扣一次、战斗无敌、取消后恢复受击且不退款、平地贴地、墙体阻挡、平台边缘自然下落、空中/蹲姿/旅行/资源不足拒绝。
- 孤立物理世界先以短帧推进超过一秒，跨过 UE 编辑器的启动下落保护；未修改引擎或直接给被测角色设置 Falling 来伪造边缘下落。
- TestV10MovementNetwork.ps1 的两名真实客户端各七个阶段通过，日志前缀 AetherV10Movement_24199eed02c2。平地闪避两端看到预测启动，体力最低均为 82，服务器确认地面与扣费；本次最终远端位移约 264 / 274 cm，采用 190–280 cm 的短联机回归范围，严格距离与延迟预算尚未验收。
- 故障阶段只在测试客户端清除尚未同步的眩晕显示，以制造预测与服务器状态差异。客户端确实先预测扣费与根运动；服务器拒绝后，两端在半秒内观察到成本恢复，最终位置回到原处附近，服务器没有扣费。
- 测试覆盖本地预测和一次拒绝恢复，不代表丢包、四人、Listen、长时间动作取消或发布性能矩阵通过。
