# v10 实际场景目标选择与过渡 RPC

本单元已接入普通游戏 HUD、E 输入和服务器交互。持久状态仍走原来的 v9 服务；这不是 v10 SQLite、统一 Offer 或 CommonUI 的完整切换。

## 附近索引与生命周期

UAetherNearbyRegistry 在各自 UWorld 中按 500 cm 网格保存弱 Actor 引用。FrontierProp / FrontierCharacter 在 BeginPlay 注册、EndPlay 注销；根组件 TransformUpdated 更新分桶。附近查询只检查覆盖范围的格子，不扫描全世界 Actor。半径上限 1000 cm，注册上限 8192，坐标有限且绝对值不超过 1e8 cm。当前角色/道具根组件固定；以后若更换根组件，须先注销再注册。

客户端只索引已复制的实例。索引不保活区域、不拥有角色权限，仍需复验对象有效性、私有归属、范围、遮挡、服务和角色状态。

## 提示与执行保持同一目标

候选评分考虑视角、距离和救援优先级；当前焦点增加 0.18 分迟滞。HUD 每 0.15 秒更新角色提示快照；E 使用这份所见快照，失效时仅刷新，不在同一次按键中执行邻居。

普通 RPC 携带 Actor 网络引用、持久 ID、动作名、所见档案版本。服务器校验原始实例；同 ID 在区域卸载后重建，也不能让旧引用操作新实例。世界服务保留冻结的持久请求及回执，在 RPC 外额外固定 Actor 和动作。旧回执查询优先于现场复验；新请求只校验指定对象。

无目标 ServerAction("Interact") 客户端入口已关闭。服务器内部脚本可即时选目标，但同样进入指定目标校验与分发器。背景对象无提示；个人火盆、木桩、搬运物、支撑绳索、浅水使用物理操作提示，不伪造 E 动作。禁用对象不抢焦点。

完整 v10 命令的独立 InteractionRevision、世界版本、ActionId 定义及 SQLite 事务尚未接入这条过渡 RPC。交易会话、未迁移服务副作用和 CommonUI 仍待完成。
