# v10 事实背压、退出排空与容器配置

运行时在事实协调者满时保存最多 1024 条已验证事件，重试保持观察 UTC 日期；集合事实按完整身份合并，磨损事件仍逐次处理。请求快照和恢复会等待保留队列，世界事实触发的其他角色结算也走同一入口。生产者无法再保留一次性任务事实时明确关闭原生场景，不能仅提示玩家重做已消失的事件。

地图退出撤销旧连接后继续轮询值对象事务，排空后关闭后端；GameInstance 退出有五秒排空窗口，超时输出明确 pending 数量和失败日志。此窗口不等于断电前的 durable inbox：尚未提交的内存事件仍可能因进程被强杀丢失，不能将它报告为崩溃恢复验收通过。

Containers.json 统一配置静态容器的稳定 ID/个人前缀、区域、位置、容量；校验数量、坐标、容量和前缀冲突。配置仅用于不存在实例的首次创建，已有持久容器的位置/库存/版本不会被模板覆盖。
