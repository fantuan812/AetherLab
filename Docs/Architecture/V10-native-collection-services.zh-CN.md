# 原生采集、委托与目标交付

源码单元未编译、未测试。

ExecuteInteraction 的实际处理器新增补给收集、每日采集、日常委托结算、目标交付/检查、巡逻记录。数据声明动作、规范目标/配方或每日模板；请求只带稳定目标、ActionId 和三个所见版本。服务器从当前目标、拥有者、范围/视线、威胁、物理前置和服务器 UTC 重建上下文，Profile 与 World 一次比较提交。

采集以永久任务证据或当天稳定采集点去重。日常委托在候选内按持久格子顺序消耗；锁定、已装备、另一个角色绑定或独立任务实例不会被配方吞掉。奖励/金币满额则整笔失败，真实消耗、领取标记和奖励均保持原样。目标检查仅可写入定义中的目标，世界目标还必须匹配正式来源。个人训练和每日灭火只接受实际物理灭火事件，没有可替代灭火的 E 交互。

现有 E 键的正式处理器已连接 LocalPlayer 原生命令服务：提示保存完整所见选择，按键使用同一选择编码一次并进入固定字节重试队列。场景实例重建或版本改变后拒绝，按键不会改选另一个目标。
