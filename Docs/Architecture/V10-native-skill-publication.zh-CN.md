# v10 原生技能发布

2026-09-21：代码未编译、未测试。没有新增运行验收结论。

- AetherSkillBinding::Publish 在修改前校验永久学习/外部来源和全部已有技能身份。每个 SkillId 保持唯一 Spec；更新 Level 和快捷位 InputID，撤销失去授权的 Spec，等级变化时取消旧执行。近战、闪避、救援等其他能力不受此技能投影管理。
- PlayerState 保存服务器原生技能账本及已见版本，拒绝回滚；失败期间标记未就绪，避免继续以旧等级放行。原生模式标记仅复制给拥有者，没有向旧 SaveGame 的反射字段追加持久数据。
- 命令运行时在完整发布适配器返回成功后，调用 PlayerState 原生技能发布，成功才排队拥有者快照。这条调用同时用于启动读取和真实事务完成。
- Frontier 角色的施法授权改为可覆盖的 SkillId 查询。原生角色根据永久/外部来源判断授权，选定数字键从原生 Hotbar 获取 SkillId，而非将位置当旧元素编号。
- 重生时公共能力照常保留，再从 PlayerState 原生账本重建元素技能。档案未就绪时即便旧基础 Spec 暂存也不能施法。
- 拥有者按快照永久等级和 GAS Spec 实际复制等级共同判断施法就绪，避免快照先到而仍按旧等级预测。角色没有原生通道时维持现有旧档案入口。

仍待：GameMode 实际存储激活/登录装配、完整装备/属性发布、资源屏障、外部技能来源的拥有者展示 DTO、真实 NPC 点数事件和重置服务。当前普通游戏仍不会自动切换到原生存储，不能据此认定技能成长完整可用。
