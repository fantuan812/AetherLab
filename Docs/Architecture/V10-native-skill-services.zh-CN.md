# v10 技能重置、拖放与外部来源

技能详情提供当前分支与全部自由学习的重置预览。预览复用纯规则计算受影响节点和实付账本退款；确认框保留明细，故事基础不撤销。协议 v3 的 ResetSkills 可选 SkillId 指定分支，空值保留全重置语义；旧协议继续拒绝新增字段。服务器仍验证导师范围、战斗、施法和冷却。

技能图支持从已授权主动节点拖到四个快捷位。拖动携带原会话/展示版本/技能及等级，目标按固定槽发 BindSkill 命令；被动、未授权与过期拖动不执行。键盘/控制器仍可在详情选择快捷位。

装备定义可配置 SkillGrants，装配时交叉检查技能等级；服务器从已提交装备重建唯一实例来源。破损装备不授予技能。铜戒提供霜凝一级样本，可从护甲商取得。拥有者复制来源用于技能页和预测许可，不写永久学习账本。

技能页在打开期间低频检查服务和施法状态，仅语义版本变化时刷新；所有持久操作仍由固定字节命令服务执行。修复原生技能详情的任务追踪入口。
