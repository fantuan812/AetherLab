# v10 只读交互与对话查询

## 实际新增内容

Core 的交互 Offer 包含目标/动作 ID、Profile/World/Interaction 三种版本、动词、图标 ID、优先级、Hidden/TalkOnly/Available/DisabledWithReason、公开原因参数、对话/任务/目标/服务引用。查询不生成 Actor、不发奖、不授技能、不修改档案。

Interactions.json schema 1 提供首批七类对象：无功能背景、可交谈镇民、登记员、旅舍、导师、补给商人、军械匠。对话包括中文人物名、正文和选项。动作 Kind 仅支持明确枚举，不能把资源字符串当脚本执行。校验上限、重复 ID、任务/目标/商店引用、选项指向、矛盾条件、不可达节点；允许返回形成对话环。

FAetherInteractionProvider 持有不可变的定义和公开状态快照。目标加载、距离、视线、行动状态、忙碌、受威胁、倒地、战斗及处理器注册状态均参与判断。没有注册处理器的动作只显示 ServiceUnavailable，不能假装已经实现。私人目标先按所有者过滤；隐藏条件省略整个动作，不返回秘密原因。

QueryDialogue 只开放当前能交谈入口的可达节点。选项再次通过同一 Offer 集合过滤：已完成/隐藏动作不出现在对话中，公开的锁定服务保留原因，普通交谈不会因尚不能训练而被吞掉。原始对话定义不能直接作为 UI 的可点击动作列表。

目标解析器按个人已提交任务状态选择第一个可行动任务及缺少的目标，提供持久锚点位置。已完成登记但未绑定据点时指向旅舍；目标全齐时返回待领奖状态；主线全部完成不产生虚假的空间目标。加载中 Actor 的绑定、个人训练对象及活动阶段的精确引导仍需场景适配器。

## 目标一致性与协议边界

Selection 保存 TargetStableId、ActionId、ProfileRevision、WorldRevision、InteractionRevision。服务器构建新的当前快照后 CheckSelection 复验完整身份及版本。错误目标不会自动换成附近 NPC；卸载、遮挡、变化的个人/世界/目标版本均拒绝原选择。稳定目标、动作和定义引用采用显式区分大小写比较，避免 FString 默认大小写折叠掩盖错拼。

Selection 目前是值契约，没有偷偷改动请求 v1。请求 v1 的 ExecuteInteraction 没有独立 InteractionRevision 字段，仍未接入实际执行；正式接入时必须显式升级协议并保留旧格式处理策略。
