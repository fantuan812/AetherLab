# 状态详情与技能节点
本单元新增真实 WBP_SkillNode 父控件，技能图保留选中、连线、平移缩放、手柄导航及固定身份拖放，节点用实际图标和授权状态展示。缺少作者资产仍报错，不冒充资源已完成。

CombatComponent 镜像灼热、冻结、潮湿、眩晕的服务器身体状态，为每次连续状态分配独立 GUID。统一查询为背包详情和 HUD 提供图标、来源、当前实际影响和可知的结束时间；未知的环境解除时间显示解除条件，不编造倒计时。数值变化刷新详情但不重建库存格子。

旅舍祝福发布失败恢复旧期望授权；到期或换生命撤销失败保留重试，技能进入不可用态并取消能力。新 Pawn 完整重建能力和被动属性，客户端过滤已过期临时来源。
