# 原生场景装配、登录与区域屏障

本单元是源码实现，未编译、未测试。历史 v9/独立规则记录不代表这些新路径已验收。

正常 Frontier GameMode 在 InitGame 打开原生生命周期，完成迁移/全库审计和资源预载后才恢复场景、安装命令协调者。登录只登记服务器身份，异步读到持久角色后才生成 Pawn；首次角色、重连和重生均进入资源生命恢复。旧 Database/Profile 只保留导航和场景查询所需投影，原生写权限启用后不会发布旧 SaveGame。

单机/本地主机使用 LocalPlayer。联网身份从引擎登录参数的在线 ID 派生固定存档键；这仍依赖部署环境的在线子系统认证，不能把传入一个有效 ID 或本单元误称为完成正式账号认证。非 Shipping LAN 开发服可显式使用 -AetherDevelopmentIdentities 与 DevProfile；默认不接收客户端随意指定的存档名。-AetherLegacyRuntime 仅保留冻结旧路径供历史回归，正常路径不回退旧档。

恢复包括原生物理、天气、世界事实投影、已有容器实体和遭遇当前波次。容器 Actor 不广播私有库存。未完成的遭遇以当前波次全血敌人继续，不保存旧引导者，不沿用旧进程 WorldTime；Relay 引导阶段不重复生成第一波。成功实例的结算名单保持不变，奖励事务仍需后续服务迁移接通。

区域卸载采用冻结/持久确认/销毁三个步骤。Reactive 子系统先完整采集并验证待冻结稳定 ID，再将这些身体移出求解和跨区域交换；Capture 仍返回冻结数据。Actor、原模拟开关、静止速度及组件 tick 状态保留到确认。SQLite CAS 提交成功后重新检查玩家距离，仍可卸载才销毁；提交失败或玩家折返恢复冻结值和原组件状态。暂停只覆盖待卸载区域，其他区域继续模拟。新加载区域从最新已提交投影恢复，恢复后再注入新增内容的初始热量。

周期检查点只拥有物理、天气和实时遭遇阶段，保留当前事务库的任务事实、容器、掉落/营地账本；同一遭遇实例的已结算名单单调合并。提交发布更新世界版本/查询缓存，不重新把整份旧物理快照灌入正在运行的场景。

地图 EndPlay 撤销旧连接和回调，排空 writer 已接受的请求；新地图重新审计。运行时发布委托内触发退出时延后释放，避免销毁仍在栈上的协调者/连接对象。
