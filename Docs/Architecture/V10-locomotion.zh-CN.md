# v10 跳跃、下蹲与冲刺的实际移动入口

本单元属于 V10-14 的部分实现。普通 Frontier 角色已使用 UAetherCharacterMovement；仍由引擎执行真实碰撞、地面与空中移动、网络预测和服务器纠正，没有用位置瞬移代替移动。

## 输入与姿态

默认 Space 跳跃、Ctrl 保持下蹲、Alt 调用 GAS 地面闪避、Shift 保持冲刺。已有用户重映射按动作名保留。跳跃 Started 只有一个入口，Completed/Canceled 调用 StopJumping；单跳允许最多 0.18 秒保持。检查动作就绪、旅行、搬运、救援和体力；空中不能重新排队起跳。

下蹲使用 Crouch/UnCrouch 与 CharacterMovement 胶囊，半高从 88 cm 改为 48 cm，移动速度 190 cm/s。跳跃或冲刺先尝试起身；低顶阻挡时保持真实蹲姿，不能跳跃或以站姿冲刺。服务端在解码跳跃移动标记后、CheckJumpInput 前复用净空检查，避免客户端已起身而服务端仍蹲着产生错误纠正。镜头用短插值缓和胶囊高度变化；完整蹲姿动画仍未接入。

## 冲刺预测与速度

冲刺意图使用 SavedMove 的 Custom_0 标记；按下和松开不能合并，纠正回放恢复原意图。服务端仍检查地面、姿态、动作和体力；网络标记不是授权。bSprinting 保留给远端姿态观察。

步行、下蹲、冲刺的地面最大速度集中在移动组件决定，默认 450 / 190 / 625 cm/s，并叠加格挡上限、冻结减速、眩晕和倒地限制。服务端沿用现有每秒 32 的冲刺体力扣除，站立不动不扣冲刺成本；现有基础体力恢复规则仍然适用。移动组件不再另扣一次。

## 保持输入清理

打开菜单或商店、失焦触发控制器 FlushPressedKeys、切换控制、执行重映射时清除跳跃、冲刺、下蹲保持和攻击保持，释放格挡。先清攻击保持再派发输入 Canceled，避免窗口失焦被误判为松键攻击。完整 CommonUI 输入上下文、控制器断连、下蹲切换模式和设置界面尚未完成。
