# 库存持久 DTO

AetherInventoryCodec 将 v10 库存值对象编码为显式小端格式，内部 SchemaVersion=1、ContentSchemaVersion=3，与外层事务存储 SchemaVersion=10 分开。格式不依赖反射字段、结构体内存布局、FName 索引或编译器 ABI。

保存包含所有实例字段、实际格子和装备引用。实例按格子排序，词条和装备映射按键排序；容器插入顺序不改变字节。字符串以长度受限 UTF-8 编码，转换不能静默替换非法字符。总载荷限制为 2 MiB，数量/词条/装备计数在分配前检查。

解码只在完整读取、版本匹配与全部库存不变量通过后替换输出。任何未知版本、过量计数、无效文本、截断或尾随数据都返回失败并保留调用方已有库存。调用者必须检查返回值，不能把读取错误当“没有档案”。

Editor 增量构建和 27 项规则测试通过，报告 Rules-55fbd5fb80b948328daf8a00d3d4c55b。新增用例核对全部截断位置、未知 DTO/内容版本、计数篡改、中文绑定身份、词条/状态/耐久/稀疏格/装备引用；真实 SQLite 文件关闭重开后完整恢复，在注入写入失败后仍读取原耐久状态。
