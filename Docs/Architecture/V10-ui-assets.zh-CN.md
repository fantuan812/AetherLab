# v10 正式 UI 资源接线

菜单根、六页、对话、物品/装备格、详情、确认、角色预览和 HUD 从统一注册表解析 Widget Blueprint 子类。基础控件、边界判断和网络意图仍由原生父类实现。缺资产会产生明确 AETHER_UI_ASSET_MISSING 错误，不把原生回退视为内容验收成功。

PrepareV10UI.py 从同一注册表制作蓝图，保留已有蓝图，不覆盖手工设计。主题为可编辑 DA_UITheme；图标由基础几何作者代码生成透明 TGA 再导入，包含物品和四系技能。技能点号 ID 转换为资源包下划线，异步详情图标带展示代数，迟到结果不会覆盖新对象。PAL_UI 明确引用蓝图、图标和主题。

HUD 拆出可编辑的资源、追踪、快捷栏、交互、目标生命容器。显示技能图标、真实服务器施法恢复比例/秒数、双手装备和锁定目标生命；没有交互/反馈/遭遇时隐藏中央面板。日常页显示服务器下一次 UTC 零点倒计时；队伍页使用公开队长标志与仅拥有者可见的邀请截止时间。
