# 三系统实施合同（2026-09-28）

基线：88818279e8a252b79c97e3ce4080720b61d7a85f，main → origin/main，UE 5.8。
开始时 Config/DefaultEngine.ini 存在用户修改；不覆盖、不提交该文件。

本轮依据用户提供的《三大系统深度审查与执行方案》推进。用户执行顺序优先：全部代码和必要资产完成前禁止编译、规则测试、启动测试；完成后仅轻量编译和简单功能测试。文档中的中途影子运行、引导编译与重型联合验收不构成额外测试授权。

## 行为与唯一写者

- 持久 Profile/SQLite：32 格、装备槽引用库存实例、原 CommandId/规范字节重试，不更改 v1～v4。
- 技能来源解析：永久/装备/临时分别记账，同技能取最高等级；快捷位不改变授权身份。
- 属性投影：一个解析结果、一个持续效果；保留 Gear 反射字段兼容，资源上限上涨不补资源、下降只裁切。
- ResourceGate：同一 LifeId 的有序资源提交；不确定预留不能超时退款；故障关闭服务器新动作入口。
- BuffRuntime：游戏 Buff 的唯一生命周期所有者；GAS 仅执行属性/标签/瞬时结果。物理热、水、冰仍由 ReactiveWorld 拥有。
- GA/WorldAction：各自执行动作，共享准入政策；提交后事实不因卸装追溯撤销。
- CMC/RMS：位移权威；动画和生成模型仅表现。
- 展示摘要：只读、按生命和修订发布；不能凭客户端倒计时撤销服务端授权。

## 有限范围

包含八类 Buff 样本、四元素兼容执行、自施增益、短引导、v5 解绑、物品能力与损坏描述、统一动作策略及表现接线。不开放随机词缀数值、合成、任意执行脚本、跨服或离线 Buff。

事件队列最多 256 个不可合并条目、每帧排空 32 条；存储慢提示 2 秒、故障 30 秒。相邻同生命/状态/速率区间才允许合并；伤害、治疗、效果到期和投影均为边界。Buff 最长 3600 秒、最多 32 层、每生命最多 64 实例、周期最短 0.1 秒、每次施加最多 16 操作。

冷却政策：新技能冷却由服务器会话的 GameInstance 账本保存，断线与地图切换期间自然流逝；换 Pawn、换位、卸装和同一服务器重连不清零。服务器进程结束后会话冷却结束，不写入旧档案或增加离线惩罚。Buff 跟随生命，旧生命待投递按 ExpiredLife 关闭。永久技能、库存与物品消耗继续由原事务系统拥有。

数据兼容：旧命令 v1～v4 的字段和编码不变；v5 追加 UnbindSkill=23。旧 Profile DTO 未增字段。Buff 药剂使用内部 ACEF/2，附 BuffId、定义修订和 UTC 到期；外层 delivery schema 仍为 1。运行期复制摘要新增字段，需要同一构建的客户端和服务器；不声明跨构建网络互通。

内容入口：城镇药品商人出售轻步药剂；铁匠出售易损练习剑/盾；旅舍交互菜单可选择效果与净化服务；Q_Main_02 后的技能树可学习三个支援技能。图标、人体、装备外观继续复用仓库已有 UE 基础/占位资源，作者轨迹属于 Items.json 的实际运行定义，无额外模型或地图资产需求。

有限目标政策：物品恢复作用于使用者；援护技能仅允许视线内 600 cm 的一个存活玩家目标，并复验目标 LifeId，不支持敌人、跨地图或离线目标。随机词缀、合成、跨服和离线 Buff 保持未开放。网络质量与生成动作质量必须另有当前候选的采样，现有代码路径不构成验收。
