# 完整 Demo 补齐契约（2026-09-30）

基线 d44b578；范围为 Design-v4 首版四人联机动作 RPG，不扩大为线上 MMO。用户要求补齐已识别系统，并去除玩法硬编码与运行时兼容层。

## 现状审计

- 已有：GAS 战斗/技能树、实例装备和商店/奖励事务、八段主线、敌人/修道院/公共活动、原生 SQLite 存档、对话服务选择、独立 MotionBricks 推理插件、动作与接触规则、打包及崩溃验证脚本。不能重复另建第二套管理器。
- 缺口：音频只见工坊临时程序音；对话页没有完整镜头/表情/字幕播放；房间发现/邀请/失败恢复不是现有队伍按钮所能替代；新手至结局尚缺玩家可见闭环与实际旅程证据。
- 数据债务：ControlledActionDefinition.cpp/ActionTiming.h 内置整套动作数值；资源装配仍有路径写死；原生启动仍自动探测并转换旧存档；世界投影仍依赖旧 DTO，需要逐调用点解耦。
- 已有制作/成长系统按首版设计扩充。复杂词缀、自由制造不因本轮而擅自加入。
- MotionBricks 已有真实推理与重定向；没有当前云端模型文件不能推断用户机器缺失。攻击接入必须保留 GAS 权威时间、提交/命中窗口、武器接触约束和取消语义，禁止由生成动作直接结算伤害。

## 实施顺序与验收

1. 单一动作契约：外置当前动作与输入时序；严格解析/交叉校验；消费端统一读取；无默认旧数值兜底。攻击生成下一步扩展同一契约，不能开第二条结算链。
2. 单一运行时存档和内容装配：移除自动旧格式导入/转发；未知版本显式失败并保留原文件；资源由装配资产/配置声明。旧存档转换如需使用只可成为独立、显式工具，不能偷偷迁移或删档。
3. 表现闭环：音频事件/材质/区域/混音与叙事镜头/表情/字幕/跳过/中断，接入现有事件和菜单；无资产时准确报告内容缺失，不能无声称完成。
4. 游戏闭环：首版成长构筑与奖励经济复核、新手/重试/任务恢复/结局、房间创建邀请加入失败重连及房主离开；复用现有事务、GAS、队伍和旅程服务。
5. 内容与交付：敌人/Boss 与环境谜题完成首版内容；美术由并行制作工作处理。性能质量、资源 Cook、客户端/服务器包和崩溃诊断必须绑定相同候选。

## 完成定义

每批必须交付实际调用链和相应回归用例，分别记录“已实现 / 未运行验证 / 剩余”，不以空类、数据样例、计划文档或脚本存在冒充完成。遵循 AGENTS 的实施期不编译/测试顺序；待代码与必要资产齐备后统一轻量验证。本环境无 UE，UE 编译、渲染、联机、Cook 均不得标记通过。来源数据缺失、资源不匹配与不支持的存档明确失败，不伪造兼容。

- 已实现：Actions.json 唯一当前 schema 1，控制动作全表、蓄力与缓冲、翻越三阶段；严格字段、有限数值、缺失/重复身份、GAS 闪避共享成本/冷却、接触/取消契约校验。删除 ActionTiming.h 数值表与动作资产 Rules 数值副本。
- 消费路径：输入/GAS 翻越与闪避/世界物件动作/受击展示/作者烘焙/帮助生成均读同一契约。动作展示只接受已登记身份；显式播放倍率与世界提交时间同速，不再覆盖调用方加速后的时长。
- 加载契约：每进程首次读取后不可变；编辑定义必须重启 Editor/Client/Server 并重新烘焙受影响动画。不存在热加载、旧 schema 转换、缺文件默认目录或数值兜底。

- 后续必须执行：Aether.Systems.Actions.*；删除/改坏 staged Actions.json 后启动必须显式拒绝；更改蓄力/翻越阶段并重烘焙后确认 GAS 与展示一致；取消/重复输入不得重复提交；专服/客户端使用相同候选及数据。
