# 首个可玩切片：断钟修道院

版本：0.2。目标是一段约 15 分钟的剑与魔法冒险；时长是首次试玩的目标，不能替代实测。本文件为制作规格，当前 AetherLab 仍为材料实验场。

## 1. 要证明的体验

玩家要在暴雨将至之前，恢复灰渡的通行，带回失踪的铸灯学徒。修道院的守卫把所有靠近钟炉的人视为入侵者，附近劫掠者还想夺走古印。战斗、探索和最后的修复选择服务同一个地方性目标。

切片必须同时证明：不用复杂法术也能完成基础交锋；同一法术在不同材质上有可理解差异；玩家会主动改变环境；救人与设施选择在返回灰渡时得到回应。

## 2. 范围锁定

| 项目 | 本片范围 |
|---|---|
| 玩家 | 第三人称人形角色；单手剑、盾；基础格挡/闪避/轻重击 |
| 法术 | 引焰、引泉、凝霜、鸣雷；四个固定快捷槽 |
| 普通敌人 | 盾卫、逐焰咒徒；共用基础人形骨架 |
| Boss | 铸钟骑士奥伦；一个场地、两段行为、可选解除旧誓结局 |
| 地点 | 灰渡入口、断桥、外庭、回廊、钟炉庭院、返回点 |
| 材料 | 木、金属、水、油、石；附加角色护甲/身体的抽象传递 |
| 持久结果 | 学徒是否救出、通路恢复方式、古印的处置 |
| 风雨 | 一套明确的局部降雨/风变化；不做全地图气象 |
| 明确延期 | 开放世界、多人、完整经济、自由建造、连续 CFD、水体任意塑形、全建筑破坏 |

## 3. 灰盒空间

地面展开尺度约 120m × 80m，通过转折、院墙和高差分隔视野。长度是初步占地预算，最终依移动速度、镜头和剑战距离调整。采用一个地图即可，不需要先引入 World Partition。

```mermaid
flowchart LR
    A[灰渡入口 / 玛蕾与委托] --> B[断桥 / 通行选择]
    B --> C[外庭 / 盾卫与咒徒]
    B --> D[维护小道 / 少量补给]
    D --> C
    C --> E[回廊 / 学徒与旧誓证据]
    E --> F[钟炉庭院 / 铸钟骑士]
    F --> G[古印处置 / 恢复通路]
    G --> H[开闸后的返回捷径]
    H --> A
```

每段入口都有可站稳观察的位置。战斗院落保留绕行空间、固定掩体和一条干燥退路；不能为展示水雷而把整个场地铺满导电水。

## 4. 首次游玩的时间安排

| 目标时段 | 场景与目标 | 玩家学习 | 必要反馈 |
|---|---|---|---|
| 0–2 分钟 | 灰渡入口，接下带回学徒与恢复通路的委托 | 移动、剑、盾；知道四个短咒的名称 | 简短演示，不连续弹出长教程 |
| 2–4 分钟 | 断桥，选择如何过浅沟 | 剑能切绳，水与霜能改变通行性 | 绳索受击痕迹、冰面强度提示、侧路可见 |
| 4–7 分钟 | 外庭，遭遇盾卫与咒徒 | 近战争取窗口；水、木构与火会改变战斗 | 敌方动作和地面危险清楚可读 |
| 7–9 分钟 | 回廊，救出学徒并看到旧誓记录 | 世界规则有用途也有代价；获得 Boss 线索 | 学徒明确说出他能帮助修复什么 |
| 9–13 分钟 | 钟炉庭院，面对铸钟骑士 | 选择剑术、环境或见证解除路线 | 每次改变护甲/誓印都改变可见行为 |
| 13–15 分钟 | 处理古印、开捷径返回 | 自己的手段影响谁得到帮助 | 渡口灯火、人物对白和设施状态变化 |

教程只在第一次遇到对应问题时给一句可行动的提示。玩家已经解决问题后不再弹出“你应该使用……”的反向说明。

## 5. 三个关键遭遇

### 断桥：先给无战斗的试验空间

桥板落在浅沟中，另一端吊着备用栈板，维护小道从桥头下方绕过去。

- 剑与工具路线：切开一段受损固定绳，让备用栈板落成斜坡。
- 咒术路线：利用现有浅水凝霜，形成局部临时踏面。
- 探索保底路线：沿维护小道绕行，花更多时间，得到少量补给。

三条路线都保持可达终点。冰融化前给出裂纹/流水征兆，玩家落水只会被送到浅滩回路，不形成必须读档的死局。冰踏面不通过规则允许玩家直接穿过整个地图边界。

实现上把水面拆成少量已创作的面片，切换冰网格与碰撞。体积、可承载状态和消融时间是关卡参数，不把一个半径很大的水球直接视为任意形状冰桥。

### 外庭：先让剑术成立，再引出环境

一名盾卫守在干燥通道，逐焰咒徒位于稍高的平台。平台附近有木棚、小油器和蓄水桶。物体的放置要符合修道院使用方式，不把红桶整齐排列成提示箭头。

可行方案包括：从干路逼近盾卫，拆招后追击咒徒；击开水桶，改变咒徒附近火势，再用雷术牵制；切断棚布绳索，短暂遮挡咒徒视线并从侧面进入。

咒徒会在看见火势或积水危险后尝试换位，盾卫会保护其撤退。这些反应有延迟与空间限制，玩家仍有机会创造优势。

该遭遇不要求精确执行一套元素顺序。用剑完成战斗是合法方案；环境路线可以节省生命、补给或时间。玩家若站进刚制造的导电区域，也会受到影响，预警与返回干路的时间必须足够清楚。

### 回廊：将知识与救人连接

学徒躲在倒塌木梁后的安全空间。普通重击足以破开已损坏的连接，也可降温后解除正在冒烟的锁扣。使用火焰会使木梁更快失去强度，但增加附近粮袋和修复材料损失；不是直接把 NPC 放在不可预测的火场中心。

救出学徒后，他告知铸钟骑士外甲的绝缘衬层已经老化，以及“守钟”誓文的实际保护对象是修道院的避难者。附近的记录印提供第二条证据。两条信息分别支持环境战术与解除旧誓路线。

即使没有救出学徒，玩家也能靠战斗完成本片；有无学徒决定后续修复方式，不决定主线是否可继续。

## 6. Boss：铸钟骑士奥伦

### 轮廓与场地

奥伦是一副由残存誓念驱动的青铜与钢制骑士铠甲，持长柄钟槌。胸口古印稳定其动作，肩甲和腿甲有明确扣件，内衬在破损后可见。造型保持骑士与圣所守卫的识别，不使用无缘由的机器人屏幕。

庭院包含一圈可以绕行的干地、可开启的水槽、两个有绝缘基座的誓印支点、一处固定掩体和位于边缘的见证台。Boss 不会因打断唯一可交互物就使战斗无法结束。

### 基础招式与剑术机会

| 招式 | 提示 | 回应 | 成功后的收益 |
|---|---|---|---|
| 横扫钟槌 | 肩部侧转、槌头拖地声 | 靠近内圈侧步或向后退 | 可轻击其侧甲 |
| 竖劈 | 明确举槌、停顿后砸落 | 离开落点；有掩体时借其限制后续动作 | 较长回收，适合重击或蓄咒 |
| 盾臂推进 | 抬左臂、前脚压低 | 绕侧或稳定格挡后撤 | 前臂扣件短暂暴露 |
| 誓印回鸣 | 胸印发亮、两处支点依次响应 | 退到安全地，选择攻击支点或见证台 | 形成有时限的机制窗口 |

第一段强调距离与拆招。失去部分外甲后进入第二段：动作更快、正面保护减少，钟槌更容易造成地面水路变化。难度来自行为改变，不能只靠提高血量。

### 三条完成路线

**剑术路线。** 通过回收窗口攻击扣件，逐步移除护甲，累积失衡后破坏胸前古印。完整生命/架势循环必须允许这条路线在合理时间内结束。不给 Boss 设置永久 99% 的物理免伤。

**环境路线。** 开启水槽并诱导骑士经过。在外甲衬层完整时，雷术主要表现为外部放电；剑击拆扣后暴露部位更容易把电能传到关键节点，造成短暂失衡。凝霜可以对受潮的外露连接件进行脆化，再由重击产生机械结果。玩家也必须管理自己的站位。

**见证路线。** 已发现两条旧誓证据的玩家，可在回鸣窗口使用见证台，逐段改写“威胁”的识别。完成之前仍需防守或控制场面。流程提供更安静的结束与额外对白，不要求玩家必须无伤；它是被创作出的任务规则，不是声称任意对话都能由物理引擎自动推导。

环境路线可以缩短战斗，见证路线提供不同结局，剑术路线保障基本可玩性。任何一个机关失去作用后，剑术路线仍可完成。

### 防止退化成固定连招题

水槽、扣件和古印之间存在多个有效时机。玩家可以只拆甲后剑战、利用水路争取一次治疗时间，或者等待见证窗口。没有把“水 → 雷 → 冰 → 重击”设成唯一推进脚本。

同一失衡窗口内的多次控制共享递减/短暂抗控，防止永久硬直。被打湿、烧热或拆掉的部件仍保留相应状态，抗控不重置这些变化。

## 7. 收尾选择与可见结果

击败或解除奥伦的旧誓后，玩家处理古印与通路。

| 选择 | 条件 | 即时结果 | 返回灰渡的回应 |
|---|---|---|---|
| 留古印在修道院，修复本地传导结构 | 学徒获救，保留必要修复材料 | 修道院灯火恢复，开闸恢复通行 | 教会感谢；铁匠与学徒成为后续维护伙伴 |
| 带回古印，以常规方式恢复渡口 | 古印完整；不要求学徒获救 | 灰渡立即获得备用灯印，修道院保持沉寂 | 渡口安全提升，后续需要处理修道院黑暗问题 |
| 损坏后改建人工通路 | 古印被破坏或玩家主动放弃恢复 | 仍能运送人员，运粮效率较低 | 本片可结束，工坊收到后续维修委托 |

选择的材料要求通过可见道具与清楚提示表现。关键古印若被破坏，留下可带回的残片，替代结局继续成立。任务不因物理连锁意外变成无提示软锁。

本片只兑现灯火、路线、两段人物对白与一项服务变化。长期粮价、全城居民行为和完整势力战争留给后续，不在结尾承诺尚未制作的复杂模拟。

## 8. 任务状态与存档契约

任务状态建议如下，名称是实现建议：

```text
NotAccepted
 → Accepted
 → CourtyardReached
 → BelfryReached
 → GuardianResolved
 → ResolutionChosen
 → Returned
```

旁路事实：`ApprenticeRescued`、`BridgeMethod`、`EvidenceRecordFound`、`EvidenceTestimonyFound`、`GuardianOutcome`、`SigilCondition`、`RepairSuppliesAvailable`、`ResolutionChoice`。

`GuardianResolved` 由击败或完成解除誓约任一条件产生；不以某块特定网格是否 Destroy 作为唯一完成依据。剧情事实使用幂等事件提交，重新进入区域不会重复发放奖励。

检查点在入口、外庭之后与 Boss 前。普通遭遇重试恢复局部临时状态，已确认的救人/古印处置按显式任务检查点保存。每个检查点保存关键反应体的权威状态或明确的重建方案，不能只恢复 Actor 位置却把破坏过的结构重置成另一个结果。

## 10. 可独立验收的制作顺序

| 顺序 | 交付块 | 放行条件 |
|---|---|---|
| P0 | 剑盾角色与一个盾卫的灰盒交锋 | 玩家能攻击、防守、闪避；无重复命中；不用法术可胜 |
| P1 | 四法术与角色反应桥 | 法力/材料正确扣除；命中有归因；玩家与敌人都受世界影响 |
| P2 | 断桥和外庭 | 至少两条通路，环境战术有效，普通资源耗尽不会锁死 |
| P3 | Boss 剑术路线 | 完整生命/架势与两个阶段；不用机关也能结束 |
| P4 | Boss 环境和见证路线 | 三条完成路线各自验收，混合使用不打坏状态机 |
| P5 | 学徒、古印选择与返回 | 三种收尾可保存/重载，关键道具损坏有替代结果 |
| P6 | 美术、音效与性能整理 | 攻击可读，危险可预测，目标硬件上的帧时间有记录 |

不在每个交付块之间重写同一套 ReactiveWorld。新增近战和任务模块沿现有输入/输出边界接入。先解决结构与行为，再决定正式特效密度。

## 11. 必须执行的验收场景

| 场景 | 应得到的结果 |
|---|---|
| 玩家不施法挑战盾卫与 Boss | 有完整可行的剑术完成路线 |
| 玩家耗尽水囊与法力到达断桥 | 仍可用绳索或维护小道前进 |
| 玩家站在与敌人连通的水面施雷 | 双方按各自护甲/接触条件收到影响 |
| 玩家拆掉盔甲但不施雷 | 剑术与其他方式仍从结构变化受益 |
| 玩家先放水、先拆甲或先打古印 | 不同顺序均不能卡死阶段状态 |
| 玩家没有找到学徒或证据 | 保留剑术路线与可完成的收尾 |
| 玩家烧毁可选材料或破坏古印 | 进入替代结果，主任务仍有结束方式 |
| Boss 前死亡、退出并重载 | 任务、装备和关键场景状态一致 |
| 特效关闭或降到最低 | 命中、相态、导电与任务结果不变 |
| 低帧率或单帧卡顿 | 无多次命中/多次扣费；反应超预算可观测 |

首次邀请 5–8 名未读设计文档的人试玩，记录路线、死亡原因、提示求助、施法与剑击的上下文。访谈重点是“你为什么这样做”“刚才为什么失败”，不只询问是否觉得画面炫。

具体完成时间与成功率在首轮试玩后定基线。若玩家不能看懂剑术机会或材料危险，先修动作、反馈和关卡信息，不用提高伤害解决可读性问题。
