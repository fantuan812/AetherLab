# V8-07 小规模联网闭环

范围：一个 Editor Development 独立服务器进程、两台同机远端客户端。脚本 `Scripts/TestV807Closure.ps1` 使用随机隔离存档前缀和固定目标收据，不读取玩家个人存档。开发身份仅适用于受信本机环境。

阶段：先让 Alpha 持有已完成前三项主线的夹具档案、提交供水事务并改变火/冰/桥/有限电源状态；Beta 晚加入并确认复制结果、个人任务差异、他人档案不可见。两客户端通过实际 ServerAction RPC 竞争同一掉落和同一木箱；AI 指令分别由非所有者和所有者远端发送。服务端检查外来刺激被私人火盆拒绝、主人刺激允许。Beta 搬箱时主动关闭客户端，确认释放携带者，再以同身份重连。最后以相同检查点重启服务器并重新连接两客户端，检查收据、唯一数量、个人任务与世界状态。

实现补充：Logout 显式释放携带物，避免等到 Pawn 销毁才释放排他锁。测试 RPC 在非 Shipping 且显式检查命令行标志的进程中生效，不提供正式玩家通用调试权限。

预先限定：单阶段正常复制收敛最多 12 秒；服务器整个首轮最多 110 秒；重启后箱子位置与保存点距离小于 25 厘米（允许刚体落地）。桥、冰、火、电源采用实际布尔/枚举状态检查；物品数量和回执严格相等。无延迟/丢包注入，无客户端全世界重模拟；日志记录客户端接收到的刚体位置和导航版本，但不声称做了平滑纠正或高延迟表现测量。

Dedicated 实际执行结果待记录。Listen 未执行，与 Dedicated 分开；四人、打包、性能和完整流程仍属方案中的后续 RC 发布门槛，不纳入日常检查。
