# AetherLab 六区十二场景全图粗模 v1

这是全局空间与连接的Blender灰盒里程碑。覆盖v4约800×800米的一个连续世界；不是正式美术完成版，不是UE可玩地图。完成本轮后停止，不继续局部精修。

## 打开与查看

打开 source/AetherLab_Global_World_Blockout_v1.blend。默认相机为全图轴测；相机列表包含标注俯视、五个区域俯视、十四个地面/尺度机位。原21机位中的地面视角相对实际支撑面的相机高度为1.55m，使用35mm镜头，不把相机高度当作角色身高。另补4张明确命名TechFill/TechWide的技术照明证据，24mm术院广角只用于三台同框；它们不修改保存源的布局/灯光，参数在独立回执中。武馆、店面的两张基准图仍暗，不能据此宣称正式灯光完成。

- 00–08集合：实际连续地形、路线、六区与复用植被
- 09：审查机位及原65骨尺度参照
- 10：仅标注俯视用的独立文字/比例尺层，不是游戏内元素
- 11：SCN与路线审查锚点，不是玩法执行器

完整Library冻结源内置全部贴图；本次普通ZIP中的恢复副本改为外置贴图，字节不变，需与贴图包解压到同一目录。当前Blender环境不支持OpenImageDenoise，源与渲染脚本均关闭该选项；预览保留有限采样噪点。未安装或调用UE。

## 世界与尺度

- 地形实际XY范围[-400,400]×[-400,400]米，X东/Y北/Z上，METRIC与scale_length=1
- 六区中心沿用v4：山径(-65,-290)、城镇(0,0)、林地(-270,0)、水工坊(270,0)、修道院(0,270)、中继(250,220)
- 子场景落点、路线折点、海拔与3/4/5/6m名义路幅为本次灰盒采用值，不是新增全局网格或通用净宽标准
- 地理路线使用连续灰盒路床；平直节点复用原4m石路。实际门洞/围栏/桥的净空单独回读，不能以名义道路宽度代替
- 路线面采用稳定的6–15mm微分层，避免与地坪及交叉路线共面产生自阴影；整备台等少数覆盖片亦有毫米级层差。此为粗模叠层策略，不是正式路缘收口或可行走台阶标准
- 目标身高1.65m用清楚的占位标尺呈现；约1.8028m旧角色仅平移作额外参照，8个网格/权重/65骨骨架不改比例
